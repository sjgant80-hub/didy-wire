The law before the transport

A protocol is a constitution: what it permits is what the mesh becomes. So the law came first, gated — and the transport (WebRTC, sound, sneakernet) can be anything that carries signed bytes.

SYMMETRY

No master, no slave — there is no role parameter anywhere in the law. Either side hellos, offers, refuses. The same functions govern both directions.

ADMISSION

A didy is admitted only with a signed charter carrying all five rights: sovereignty, privacy, security, legible-memory, right-to-refuse. A peer that won't declare your rights is not a peer.

DEFAULT REFUSE

Nothing enters a union without an explicit yes. Silence is a no. The acceptance receipt is the same bytes on both ends.

RED LINE · NO EXFILTRATION

Envelopes only from admitted peers; only what was offered AND accepted crosses. A fold marked private cannot even be offered.

RED LINE · NO SURVEILLANCE

A refused shard leaves no copy — the refusal carries the why and never the content.

RED LINE · NO ORDERS

The wire has no execute verb. Only hello / offer / accept / shards exist. Anything else: "the wire carries folds, not orders."

The three red lines were named by the resident node itself — the didy that will live on this wire was asked what it must never do, before the law was written. Its answers became refusal tests.

Use the law

The kernel is transport-agnostic and crypto-injected — bring Ed25519 (node:crypto, as CI proves) or WebCrypto, and any wire that moves signed bytes.

import { helloOf, admit, offerOf, accept, receive } from './wire.mjs';

const h = helloOf('my-didy', myPubKey, ['sovereignty','privacy','security','legible-memory','right-to-refuse']);
send({ ...h.payload, sig: sign(h.signable) });          // admission, signed
const peer = admit(theirHello, verify);                  // both sides, same law
const off  = offerOf('my-didy', myShareableFolds);       // private folds refuse the offer
const yes  = accept(theirOffer, true);                   // default refuse — true must be said
const got  = receive(theirShards, admittedPeers, verify) // tamper → refused, no copy kept

Claims and limits

PROVEN — GATED, 43/43

  • symmetric: swap every role and the law reads identically (tested, not promised)
  • admission requires all five rights, signed; the missing right is named
  • default refuse; one private fold refuses a whole offer, loudly
  • a tampered envelope is refused with the why and never the content
  • a fold that crossed the wire is reused by the collective collapse — proven with real Ed25519 in CI

NOT CLAIMED

  • this page runs both didys in one document — a demo of the LAW; real transport is yours (WebRTC, sound, sneakernet — anything that carries signed bytes)
  • signatures here use your browser's WebCrypto (algorithm shown in the transcript); the CI proof uses Ed25519
  • no discovery, no NAT-punching, no telemetry — the law only; smaller than it looks, on purpose
